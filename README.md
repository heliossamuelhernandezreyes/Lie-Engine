# Lie Engine

Research-stage camera-indexed image-based rendering system built on Godot 4.x.

The physical world remains 3D; its appearance can be selected from captured angular views. This repository is the independent home for Lie's renderer, capture tooling and reproducible experiments. **Performance and visual benefits are hypotheses, not established results.**

Development happens through reviewable branches and pull requests. See the first prototype PR for implementation, tests and limitations.
